# FastNET Liquid Glass icon layers

These 1024 × 1024 SVG files are ordered back-to-front for Apple Icon Composer:

1. `01-background.svg` — base blue field
2. `02-color-field.svg` — cyan and indigo depth shapes
3. `03-wifi.svg` — Wi-Fi identity layer
4. `04-switch-arrows.svg` — configuration-switching layer

The source artwork intentionally contains no blur, shadow, specular highlight, or
canvas mask. Icon Composer and macOS apply those effects dynamically.
